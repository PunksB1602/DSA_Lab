
## Data Structure and Algorithms Lab (4th Semester, 2023/24)

This repository contains a set of C and C++ programs developed as part of my Data Structure and Algorithms laboratory in the 4th semester (2023/24). The primary aim of these programs is to provide hands-on experience with fundamental data structures, classic algorithms, and their practical implementation.

### Overview

The programs in this collection cover:

- **Sorting Algorithms:**
	- Bubble Sort
	- Merge Sort
- **Linked Lists:**
	- Singly Linked List (basic and menu-driven)
- **Stacks and Queues:**
	- Stack (array-based, with and without menu)
	- Queue (array-based, C++ class)
- **Trees:**
	- Binary Search Tree (BST) operations

Each program demonstrates the core logic and operations for its respective data structure or algorithm, with some files providing interactive, menu-driven interfaces for user input and testing.
